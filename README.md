# Portafolio de Jersay · eva-camaleon

Sitio estático de una sola página, responsive y preparado para SEO.

## Sitio publicado

La dirección configurada es:

```text
https://lupuslomas-beep.github.io/
```

El nombre profesional Jersay, las variantes del alias eva-camaleon, la URL canónica y el sitemap están configurados para que los buscadores puedan relacionarlos.

## Ver en tu computadora

Abre `index.html` directamente o ejecuta desde esta carpeta:

```bash
python3 -m http.server 8080
```

Luego visita `http://localhost:8080`.

## Publicar e indexar en Google

Puedes arrastrar esta carpeta a Netlify, subirla a GitHub Pages o desplegarla en cualquier hosting estático. Después:

1. Añade el sitio a Google Search Console.
2. Verifica la propiedad de la URL.
3. Envía `https://lupuslomas-beep.github.io/sitemap.xml`.
4. Solicita indexación de la página principal.

La aparición en resultados depende de Google y puede tardar. Usar siempre el mismo nickname en el sitio y en perfiles públicos ayuda a asociar la búsqueda `eva_Camaleon` con esta página.
